# Hotel Occupancy Forecasting

A Flask API for forecasting hotel booking cancellations and bookings using machine learning models.

## Description

This project uses machine learning models to predict hotel booking cancellations and bookings. The models are trained using historical data and various features extracted from the booking dates. The API provides endpoints to predict cancellations and bookings based on check-in and check-out dates.
